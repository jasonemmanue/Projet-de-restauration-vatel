# CANTINE VATEL

Gestion de cantine scolaire et d'entreprise en Côte d'Ivoire : porte-monnaie électronique, réservation de
repas avant l'heure limite, ticket QR scanné au comptoir, back office des menus et des stocks.

En construction.

- `api/` : API FastAPI
- `app/` : application Flutter, Android, iOS et web
- `site/` : site public Next.js
- `docs/` : cahier, modèle de données, contrat d'API, charte, plan et audit
